## 이야기와 선택

공통 8씬, 두 연애 경로 각 본편 14씬+분기 장면 2씬, 두 우정 경로 각 5씬, 결말 13씬으로 전체 63씬·404노드입니다. 한 번에 모든 장면을 방문하지는 않습니다.

지안은 실력과 취향을 알아보는 만남에서 시작해 개인적인 약속·관계 확인·공개 방식·일과 연애의 경계로 이어집니다. 나래는 함께 시간을 고르고 취향을 나누는 과정에서 출발해 상대의 호의를 혼자 해석하는 문제와 서로의 선택을 존중하는 일로 이어집니다.

- 공통 마지막 장면에서 연애·우정·솔로 경로를 직접 선택합니다.
- 노트 대여, 데이트 활동, 대화 방식 등을 플래그로 기억하고 뒤 장면에서 언급합니다.
- 지안의 작업/영화 선택, 나래의 음악/스케치 선택은 서로 다른 씬을 방문하고 다음 장면에서 합류합니다.
- 관계를 천천히 진행하거나 입맞춤을 미뤄도 좋은 결말을 볼 수 있습니다.
- 관계 공개와 일정 조율, 갈등 뒤의 사과를 다룹니다. 마지막에는 어떤 관계로 남을지 직접 답합니다.
- 한 번의 애매한 선택에 영구 배드 플래그를 붙이던 구도를 없앴습니다. 현재 배드 플래그는 마지막에 관계를 정리하는 명시적 선택에 연결됩니다.

## 아트와 UI

과한 피부 광택과 사진 같은 조명 대신 단순한 선·색면·절제된 그림자로 스타일을 맞췄습니다. AI 생성 이미지이며 수작업 작화를 뜻하지 않습니다. 원본과 프롬프트 방향은 [아트 기록](ART_DIRECTION.md)을 참고하세요.

- 네 인물의 투명 스프라이트: 지안·나래 각 4표정, 도윤·시혁 각 2표정. 기존 8개 표정 이름은 의미에 맞는 프레임으로 매핑합니다.
- 낮/밤 배경 12개, 발표실 1개, 타이틀 배경 1개.
- 지안의 커피·옥상, 나래의 귀갓길·강변 이벤트 CG 4장을 본편에 연결했습니다.
- 컷신 방문 시 해금하며 저장·불러오기 후 같은 장면을 복원합니다.
- 갤러리 NEW 표시는 이미지를 실제 열어봤을 때만 지웁니다.
- 인물이 이동하면 이전 위치를 지우고, 명시적 퇴장과 컷신 전환을 지원합니다.
- 메뉴를 통합하고 모바일 배치, 글자 크기, 읽기 속도, 포커스 이동과 모션 줄이기를 지원합니다.
- 컷신은 대사창 위에 배치합니다. 세로 화면에서는 에셋별 초점으로 인물과 손을 중심에 두고, 장면 감상 모드에서는 전체 그림을 볼 수 있습니다.
- 낮·저녁·밤·긴장 분위기에 맞는 간단한 Web Audio 배경음과 선택 효과음을 추가했습니다.
