# 캠퍼스 로맨스 리디자인 제안

이 문서는 현재 코드를 검토하고 요청된 방향을 정리한 **개발 제안**입니다. 아래 설정·씬 수·분기·UI는 별도 표기한 이미지 시안을 제외하면 아직 구현되지 않았습니다. 본편의 정식 설정으로 확정한 내용도 아닙니다.

검토 기준: 공통 씬, 지안 루트 전체, 캐릭터·세계관·루트 정의, 분기 엔진, 플레이·타이틀·갤러리·이미지 UI 코드. 로컬 실행과 브라우저 연결 시간 초과로 실제 플레이 화면과 기존 PNG 원본의 투명도·손상 여부는 확인하지 못했습니다.

## 목표와 우선순위

성인 대학생들의 캠퍼스 로망을 중심에 둡니다. 함께 시간을 보내며 서로에게 끌리고, 원하는 관계를 선택하며, 그 선택이 이후 생활과 관계에 영향을 주는 작품을 목표로 합니다. 친밀한 장면의 앞뒤에 감정·사건·관계 변화가 이어져야 합니다.

1. 주인공과 연애 대상, 기존 인연, 학기 일정을 먼저 정합니다.
2. 지안·나래 두 루트에 서로 다른 연애 경험과 충분한 전개를 만듭니다.
3. 중간 이벤트 CG 지원과 이미지 표시 문제를 해결합니다.
4. 대표 루트 한 편을 처음부터 끝까지 플레이하며 이야기·선택·컷신·모바일 UX를 함께 검토합니다.
5. 이 기준이 안정된 뒤 추가 히로인과 후일담을 확장합니다.

남성 주인공 시점의 이성 로맨스를 기본 방향으로 제안합니다. 한도윤과 정시혁은 친구·프로젝트 동료·진로 갈등의 당사자로 활용할 수 있습니다. 남성 캐릭터에게 잘해준 선택이 자동으로 연애 루트 진입으로 이어지지 않도록 우정과 연애를 구분합니다.

## 설정이 실제 사건을 만들게 하기

설정집의 항목을 늘리는 데서 끝내지 않고, 각 설정이 약속·동선·갈등·호칭을 바꾸도록 합니다.

| 먼저 정할 항목 | 사건에 연결하는 예 |
| --- | --- |
| 학번·나이·휴학 기간·기존 팀 활동 시기 | 왜 나래가 같은 학년 주인공을 선배라 부르는지, 지안과 언제 같은 팀이었는지 설명 |
| 주인공의 복학 목표와 약점 | 전공을 따라잡고 싶어 맡은 일을 숨기다 약속을 놓침. 상대에게 도움받을 이유도 생김 |
| 지안의 졸업·취업 일정과 작년 실패 | 면접 준비와 팀 마감이 겹침. 자신이 통제하려는 이유를 구체적 사건으로 보여줌 |
| 나래의 수업·근무표·생활비 | 어떤 요일에 만날 수 있는지, 비싼 데이트보다 어떤 시간을 좋아하는지 달라짐 |
| 동아리 규칙과 팀 역할 | 부품 구매·야간 출입·작업 분담 때문에 함께 있어야 할 현실적인 이유가 생김 |
| 대회 일정·예산·시제품 목표 | 4월 센서 검증, 5월 통합 시연, 6월 발표처럼 시간과 성취가 보임 |
| 통학·자취·막차·귀가 동선 | 기다릴지 다음에 만날지, 오늘 약속을 어디까지 이어갈지 선택할 상황이 생김 |
| 친구들의 기존 관계·대화방 문화 | 둘 사이의 변화를 주변이 알아차리고, 공개 여부가 실제 생활에 영향을 줌 |

캠퍼스 장소에도 역할을 나눕니다. 동아리방은 일과 집단 관계, 후문 카페는 수업 밖의 일상, 도서관은 목표와 공부, 축제는 서로의 다른 모습, 귀갓길은 둘만의 대화, 개인 공간은 관계가 충분히 깊어진 뒤의 생활을 보여주는 장소가 됩니다.

## 먼저 완성할 루트의 규모

첫 확장 목표로 **공통 8개 씬 + 히로인별 14개 씬 + 엔딩**을 제안합니다. 한 번의 플레이는 약 23개 씬을 거치며, 선택에 따라 다른 장면을 방문합니다. 이는 제작 계획용 목표치이며 현재 분량이나 플레이 시간을 뜻하지 않습니다.

| 단계 | 공통 루트에서 할 일 |
| --- | --- |
| 복학과 재회 | 인물 이름을 한꺼번에 설명하기보다 주인공의 작은 문제를 함께 겪기 |
| 첫 프로젝트 | 역할과 서로의 실력, 호흡을 보여주기 |
| 작업 밖의 시간 | 학식·공강·단톡·귀가 동선에서 개별 취향과 유머 드러내기 |
| 다른 모습 | 축제 준비나 개인 작업에서 평소와 다른 매력 발견 |
| 첫 마찰 | 주인공에게도 책임이 있는 사건과 회복 가능성 만들기 |
| 둘만의 약속 | 친절과 연애 관심을 구분하고 플레이어가 누구와 가까워질지 선택 |

히로인별 14개 씬은 대략 ‘따로 만나기 시작하는 4개 → 관계가 달라지는 4개 → 갈등과 관계 조율 4개 → 학기 말 선택과 후일담 2개’로 구성합니다. 매 씬마다 새로운 정보·행동·관계 변화 중 하나가 있어야 하며, 같은 고민을 반복하는 장면은 줄입니다.

### 지안: 함께 일하던 선배를 이성으로 다시 보는 루트

- 끌림의 시작: 어려운 문제를 풀 때의 집중력, 예상 밖의 장난, 서로의 실력을 인정하는 순간.
- 주인공의 매력: 단순히 위로를 잘하는 사람이 아니라, 자기 몫을 끝내고 약속을 지키며 때로는 지안에게 배우는 사람.
- 작업 밖의 시간: 대회와 무관한 첫 외출, 선후배 호칭이 잠깐 어색해지는 대화, 먼저 개인 연락을 해오는 지안.
- 관계의 진전: 둘 다 시간을 더 보내고 싶다는 의사를 드러내고, 그날의 선택이 다음 만남과 말투에 남음.
- 갈등: 팀 앞에서 보이는 태도와 둘이 있을 때의 태도 차이, 졸업 이후의 계획, 업무와 연애의 경계.
- 마무리: 주인공이 지안을 구해내는 결말에 더해, 두 사람이 각자 할 일을 하며 관계를 지속하는 방식을 선택.

### 나래: 모두에게 친절한 사람과 둘만의 관계를 만드는 루트

- 끌림의 시작: 디자인 감각과 재치, 상대에게 맞장구만 치지 않고 자기 취향을 밀어붙이는 모습.
- 주인공의 매력: 형편을 대신 해결해주는 사람보다, 나래의 일정과 선택을 기억하고 함께 즐길 줄 아는 사람.
- 작업 밖의 시간: 마감 후 짧은 산책, 서로의 플레이리스트, 적은 돈으로 정한 데이트가 둘만의 취향으로 남는 경험.
- 관계의 진전: 다른 사람에게도 하는 친절과 주인공에게만 하는 제안의 차이가 행동으로 보임.
- 갈등: 숨기는 관계와 사적인 관계의 차이, 거절을 어려워하는 습관, 주인공이 혼자 해석한 호의.
- 마무리: 나래가 쉬어갈 곳을 얻는 것과 함께, 스스로 약속을 고르고 먼저 만나자고 하는 변화.

서로의 취약성을 알게 되는 장면 뒤에는 즐거움·존경·욕망·선택이 함께 쌓여야 합니다. 친밀한 장면은 두 사람의 의사가 드러나는 전환점으로 두고, 다음 날 연락·호칭·거리감·주변 관계가 달라지도록 합니다. 관계를 천천히 진행하는 선택에도 충분한 로맨스와 후일담을 제공합니다.

## 선택지는 서로 다른 관계 경험을 만들기

| 상황 | 선택 A | 선택 B | 뒤에서 달라질 것 |
| --- | --- | --- | --- |
| 팀 회의에서 지안이 책임을 떠안음 | 회의 중 공개적으로 역할 분담 제안 | 회의 후 둘이 이야기하고 함께 제안 | 지안의 체면·신뢰, 팀원들이 보는 두 사람의 관계 |
| 프로젝트 긴급 수정과 이미 잡은 약속이 겹침 | 오늘은 작업에 남고 약속을 구체적으로 다시 정함 | 역할을 인계하고 약속을 지킴 | 팀의 신뢰와 이후 검증 부담, 상대가 기대하는 시간 |
| 관계를 누군가 눈치챔 | 둘이 합의해 친구들에게 알림 | 지금은 비공개로 두고 이유를 설명 | 단톡·동아리 행사에서의 대사와 행동 |
| 서로 더 가까워지고 싶은 순간 | 지금 마음과 원하는 관계를 직접 말함 | 다음 약속을 잡고 조금 더 천천히 알아감 | 다음 날의 연락, 관계를 확인하는 시점, 서로의 기대 |
| 나래의 짧은 공강과 동아리 모임이 겹침 | 둘만의 짧은 점심을 먼저 약속 | 모임에 함께 가고 귀갓길을 따로 잡음 | 개인적인 대화와 집단 안에서 보는 모습 |

선택지가 상대의 기분을 맞히는 퀴즈가 되지 않게 합니다. 선택 직후의 짧은 반응 외에 다음 씬 또는 뒤 장에서 결과가 다시 나타나야 합니다. 상대의 상황을 알아보고 타협하거나 이전의 실수를 풀어갈 기회도 둡니다.

시스템은 호감도 하나에서 벗어나 신뢰·연애 관심·해결되지 않은 갈등과 사건 플래그를 구분하는 방향을 검토합니다. 플레이 화면에는 숫자 대신 관계의 표현과 장면 반응을 보여주는 편이 어울립니다. 루트 진입은 최고 점수 자동 선택보다 둘만의 약속을 잡는 장면처럼 플레이어의 연애 의사가 드러나는 선택으로 처리합니다.

## 컷신과 에셋

새 CG는 ‘관계가 달라졌다는 것을 그림으로 기억할 장면’에 배치합니다.

- 공통: 재회한 동아리의 첫 합동 작업, 축제의 밤 등 대표 장면.
- 각 루트: 처음 다른 매력을 발견하는 순간, 첫 외출, 관계를 확인하는 순간, 화해, 주요 엔딩.
- 같은 장소라도 인물의 거리·옷차림·시선·조명을 달리합니다. 대사 몇 줄이 바뀔 때마다 새 CG를 넣기보다 중요한 전환을 강조합니다.
- 엔진에서 중간 이벤트 CG 지정·표시·해금·저장 복원을 지원한 뒤 실제 씬에 연결해야 합니다.

### 캐릭터가 네모로 보이는 문제

코드에 이미지 실패 시 사각형 대체 UI가 있으며, 캐릭터 생성 프롬프트에는 ‘plain neutral background’가 들어 있습니다. 하지만 이 두 사실만으로 현재 PNG에 불투명 배경이 있는지, 어떤 파일이 손상됐는지 확정할 수는 없습니다.

1. 파일 존재·실제 이미지 디코딩·배포 URL·로드 실패를 확인합니다.
2. 인물 PNG의 알파 채널과 가장자리 배경을 검사합니다. `object-contain`은 그림 속 배경을 지워주지 않습니다.
3. 스프라이트를 같은 캔버스·눈높이·발 기준으로 정렬하고 얼굴과 손, 옷차림을 대조합니다.
4. 표정 이미지를 먼저 로딩하고, 실패 시 같은 인물의 기본 표정으로 대체합니다.
5. 주요 배경은 다음 씬 진입 전에 준비하고, 원본 PNG를 보관한 채 배포용 이미지를 최적화합니다.

## UI/UX 개선안

실제 화면 검증 전 단계의 코드 기반 제안입니다.

| 영역 | 제안 | 확인 기준 |
| --- | --- | --- |
| 타이틀 | 작품 소개·이어하기·새 시작의 우선순위 정리, 이름 입력은 새 시작 흐름으로 이동 | 기존 플레이어가 이어하기를 바로 찾고 새 저장 시작과 구분 |
| 플레이 상단 | 핵심 조작만 남기고 저장·불러오기·설정·타이틀은 메뉴로 통합 | 모바일 한 줄에서 주요 조작 가능, 얼굴을 가리지 않음 |
| 대사창 | 글자 크기·줄 간격 조절, 화자 구분, 일정한 높이와 충분한 대비 | 긴 한국어 문장과 큰 글자 설정에서 잘리지 않음 |
| 인물 배치 | 화면 비율별 크기·위치, 화자 중심 구도, 등장·퇴장 처리 | 360px 폭에서도 얼굴과 선택지 구분, 같은 인물 중복 표시 방지 |
| 컷신 | 이미지별 초점·크롭 지정, 가로·세로 화면 검토, 부드러운 전환 | 얼굴·손·중요 소품이 잘리지 않으며 장면 전환 때 번쩍이지 않음 |
| 선택지 | 본문을 함께 기억할 수 있는 배치, 긴 문장 줄바꿈, 키보드 선택 | 버튼이 겹치지 않고 선택 결과가 대사·행동으로 이어짐 |
| 관계 | 즉시 +숫자 피드백 대신 관계 변화 표현을 기본으로 검토 | 정답 선택을 찾는 게임으로 느껴지지 않음 |
| 갤러리 | 인물·챕터별 탐색, 스포일러를 줄인 해금 힌트, 이미지 확대 조작 | 이미지를 실제 열어본 뒤 NEW 표시가 해제됨 |
| 저장 | 챕터·날짜·주요 인물·장면 썸네일 강화 | 저장을 열기 전 대략 어느 순간인지 파악 가능 |
| 접근성 | 키보드 포커스, 대사창 조작, 모달 포커스·복귀, 모션 줄이기 | 마우스 없이 핵심 기능 사용 가능 |

현재 갤러리 코드는 방문 시 해금된 이미지를 모두 ‘본 것’으로 기록합니다. 실제로 확대한 이미지별로 기록하도록 바꾸면 NEW 표시가 사용자 행동과 더 잘 맞습니다.

## 첫 개편의 완료 기준

- 세계관·캐릭터·대사의 학번, 휴학, 첫 만남과 기존 인연이 일치합니다.
- 대표 히로인 한 루트에 서로에게 끌리는 구체적 계기와 작업 밖의 만남, 관계 진전 뒤의 변화가 있습니다.
- 주요 선택은 뒤 장면에 반영되며 갈등을 조율하는 경로가 있습니다.
- 중간 CG가 본편에서 표시되고 갤러리 해금과 저장·불러오기 후 복원이 동작합니다.
- 인물 스프라이트의 불투명 사각 배경·배포 경로·이미지 로드 실패를 실제 화면에서 점검합니다.
- 모바일 세로·가로와 데스크톱에서 대사·인물·선택지·컷신 구도를 확인합니다.
- 콘텐츠 검증·분기 테스트·빌드 후 대표 경로를 직접 플레이합니다.
